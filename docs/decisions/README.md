# Decision records

One file per decision that would otherwise have to be re-derived from the code. SPEC §16
item 8 asks the README for "a decision you reversed and why" — this directory is where
that answer comes from, written while the reasoning is fresh rather than reconstructed
months later.

Format: context, decision, consequences. Superseded records stay, marked `Superseded by
ADR-NNNN`, because the trail is the point.
